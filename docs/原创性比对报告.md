### 重合项全部是平台强制命名

| 类别 | 具体项 | 说明 |
|---|---|---|
| Win32 API / 宏 | `SUCCEEDED` `FAILED` `GetLastError` `GetProcAddress` `SetEvent` `GetVersion` `GetCurrentProcessId` `SetWindowsHookEx` `GetWindowThreadProcessId` `HRESULT_FROM_WIN32` | 系统提供，任何实现都只能用这些名字 |
| COM 接口方法 | `SetSite` `GetSite`（`IObjectWithSite`） | 微软定义；实现 TAP 站点必须实现 |
| XAML 诊断接口方法 | `OnVisualTreeChange` `OnElementStateChanged` `AdviseVisualTreeChange` `GetIInspectableFromHandle` `GetHandleFromIInspectable` | 来自 SDK 头 `xamlOM.h`，接口方法名固定 |

| 通用词 | `Content` `GetParent` `switch` `insert` | 语言/框架通用词 |

即：**这些名字换任何人写都必须这么叫**，属于"不受版权保护的事实性技术知识"。

## 三、实现机制对照（架构层面完全不同）

| 维度 | TranslucentTB | 本项目 |
|---|---|---|
| 注入侧结构 | `ExplorerTAP`（COM TAP + IDL 接口定义）+ `ExplorerHooks`（`SetWindowCompositionAttribute` detour） | `GlassBoot`（纯 C 引导 DLL，无 COM 初始化）+ `GlassTAP` + 自研 `channel` 通信层 |
| 模糊实现 | 在 XAML 树内挂 **Direct2D 特效**：`XamlBlurBrush` / `GaussianBlurEffect` / `CompositeEffect` / `FloodEffect` | **GDI+ 自行抓屏 → 盒式模糊 → 按背景亮度烘焙位图**（`glass.cpp`），完全不使用 D2D/XAML 特效 |
| 配置与界面 | C++/WinRT + XAML 页面（`Xaml/Pages/*`、`Xaml/Controls/*`） | 自绘 Win32 + GDI+（`settings.cpp`），无 WinRT UI |
| 功能范围 | 仅任务栏外观（透明/亚克力/颜色） | 任务栏透明 + 岛台面板 + 顶部标签栏 + 音频波动条 |

`glass.cpp` 与对方模糊/注入相关文件**标识符重合 0**，机制上也是两条不同的技术路线。
