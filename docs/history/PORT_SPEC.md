### 0.3 玻璃渲染管线（`glass_render.py`）

1. `frost(img, radius, factor=4, saturation=1.7, brightness=1.08)`：缩小 1/4 → 高斯模糊(radius/4) → 饱和度 ×1.7 → 亮度 ×1.08 → 双三次放大
2. `_vgrad`：竖向渐变覆盖层，alpha 从 a_top(0.52) 线性到 a_bot(0.60)
3. `build_surface(w,h,backdrop,dark,radius,blur=14)`：frost(深色 brightness 1.12) + 叠色渐变 + 顶部镜面高光（仅圆角时，高度 `min(12, h*0.06)`，alpha specular→0）
4. `add_border`：1px 圆角内描边（白 52α / 白 190α）
5. `add_hairline`：底部 1px 分隔线（白 84α / 黑 24α）
6. `draw_capsules`：叠加胶囊高亮
7. `to_chroma`：圆角外填洋红 `#ff00ff` 后二值抠色（C++ 版改用真 alpha，效果更细腻且无紫边）
8. `average_color` / `readable_text`：按成品平均色用 WCAG 对比度校正文字色（对比度 <4.0 → 纯白/纯黑；次级 <3.0 → `#E4E5EA`/`#3C3D42`）
9. `pick_global_dark`：整屏缩略采样 → 相对亮度 → 深色优先（对比度 ≥6.0 用深色；否则若浅色 ≥4.5 用浅色）

## 1. 顶部标签栏（`ui/tab_bar.py`，423 行）

### 功能
- ⬜ 满屏宽度贴顶部，高度 `px(24)`
- ⬜ 标签**等分**可用区：`tabW = (屏宽 − 4×px(24)) / 标签数`
- ⬜ 右侧固定 4 个系统图标，每个宽 `px(24)`：✂ 截图 / 🗑 回收站 / 🖥 此电脑 / ⚙ 设置
- ⬜ 点击标签 → 切换激活并展开面板；右键标签 → 上下文菜单
- ⬜ 悬停标签 → **35ms** 停留阈值后触发面板（扫过不弹，停顿即弹）
- ⬜ 指针移出 → 取消待触发的悬停、清悬停态、通知面板收起
- ⬜ 右键图标区不响应
- ⬜ 右侧图标动作：截图 `snippingtool.exe`、回收站 `explorer.exe ::{645FF040-...}`、此电脑 `explorer.exe ::{20D04FE0-...}`、设置 → 打开设置窗口

### 样式
- ⬜ 玻璃模式：整条模糊背景 + 底部分隔线，**无圆角**（radius=0）
- ⬜ 激活/悬停标签 = **贴合文字的胶囊**：宽 = 文字宽 + `px(26)`，高 = `h − 2×px(4)`，圆角 = 高度/2，水平居中于自己的格子，左右各留 `px(6)` 边距
- ⬜ 激活胶囊 = capsule_strong（白 48α），悬停胶囊 = capsule（白 26α）
- ⬜ 右侧图标悬停也有胶囊（左右内缩 `px(3)`）
- ⬜ 标签文字 Microsoft YaHei 10pt，激活用 `text`、非激活用 `text_dim`，居中
- ⬜ 右侧图标 Segoe UI Symbol 12pt，悬停用主文字色，否则 dim
- ⬜ 非玻璃模式：主题底色 + 激活格 active 底 + 悬停格 hover 底 + 格子分隔竖线 + 激活标签底部强调线（`accent`，左右各内缩 25%，高 `px(2)`）

## 2. 悬停展开面板（`ui/hover_panel.py`，805 行）

### 功能
- ⬜ **独立置顶窗口**，贴在标签正下方，宽度 = 标签宽度
- ⬜ 高度 = `min(max(屏高/4, 行高+2×pad), 屏高×0.6)`
- ⬜ **纵向列表**：每行 = 图标 + 程序名
- ⬜ 行高 `px(字号×2.6)`，图标边长 `px(字号×1.8)`（缺省字号 10 → 行高 px(26)、图标 px(18)）
- ⬜ 图标：真实文件图标（大图缩放）；取不到时画占位块（文件夹绿 `#4E7A57`，文件灰 `#3A3D44`）+ 前两字/📁
- ⬜ 名字放不下 → 截断加 `…`
- ⬜ 行悬停高亮（玻璃模式圆角块，内缩 `px(2)`）
- ⬜ 点击行 → 启动（`os.startfile` 等价 ShellExecute）
- ⬜ 右键行 → 快捷方式菜单
- ⬜ **滚动**：条目超视口时右侧细滚动条（宽 `px(4)`，圆头，轨道+滑块）；滚轮每次 3 行；可拖动滑块 / 点轨道翻页
- ⬜ 空标签时居中提示「右键标签添加快捷方式」
- ⬜ 壁纸模式但该标签没壁纸 → 底部一行提示「壁纸模式 · 右键标签 → 设置此标签壁纸…」
- ⬜ 面板显示期间 150ms 轮询：鼠标既不在面板也不在标签栏 → 收起；前台窗口变化 → 重抓背景
- ⬜ 面板自身不抢焦点，显示前抓背景（避免拍到自己）

### 样式
- ⬜ 玻璃卡片：圆角 `px(14)` + 1px 描边 + 圆角外透明
- ⬜ 面板模糊半径 30（比标签栏重），深色 brightness 1.12
- ⬜ 内容边距：玻璃模式 `row_x1=px(6), row_x2=w−px(6), top=px(6)`，图标 x=`px(10)`，图标与文字间距 `px(10)`，文字右侧留 `px(12)`
- ⬜ 行高亮色 = `blend(面板平均色, 白, 0.13)`（深）/ `blend(avg, 黑, 0.07)`（浅）
- ⬜ 滚动条轨道 = `blend(avg, toward, 0.12)`，滑块 = `0.42`
- ⬜ 非玻璃模式：theme.panel_bg 底 + 斑马纹（偶数行 active 色）+ 方形行高亮
