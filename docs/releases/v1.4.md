# 中文

## hotrainy v1.4

Windows 11 桌面增强小工具：**任务栏真透明 + 岛台面板 + 顶部标签栏 + 音频波动条**。
纯 C++ / Win32 + GDI+ 手写，静态链接 CRT —— **免管理员、免运行库、免注册**。

### 下载安装

1. 下载 **`hotrainy_setup.zip`**（0.63 MB）
2. 解压得到 `hotrainy_installer.exe`（1.33 MB，单文件）
3. 双击 → 选择安装位置 → 确认。会自带桌面快捷方式和开始菜单项
4. 启动后右键托盘图标 → **设置**，打开「透明」「岛台」「音频条」

卸载：运行安装目录里的 `uninstall.cmd`（会重启一次资源管理器释放注入的 DLL，然后删干净）。

### 本版新增

**音频波动条**
- 随系统响度起伏的频谱条，带峰值保持与静音态
- 横向/纵向长度可调（设置里 +/−，每下 50 像素）
- 四种波动方向：向上 / 向下 / 向左 / 向右（切换方向自动对调宽高）
- 按住本体拖动即可移动，位置与尺寸持久化
- 层级为普通窗口（不置顶，不挡其他软件）

**单文件安装程序**
- 双击可选安装路径，自动建桌面/开始菜单快捷方式
- 不写系统目录、不碰开机自启（想开机启动在程序设置里开）

**一键卸载脚本 `uninstall.cmd`**
- 结束程序 → 删自启项与快捷方式 → 重启资源管理器释放注入的 DLL → 删程序文件/配置/日志/壁纸 → 校验残留 → 自删

**顶部标签栏**
- 全屏游戏 / 全屏视频时不再弹出（`SHQueryUserNotificationState` 判断）
- 设置里新增「壁纸适用标签」，可为每个标签面板单独设壁纸（按标签 id 记忆，标签增删不错位）

### 本版修复

- 启动快捷方式：工作目录改为**目标自身目录**、路径正斜杠规范化 —— 修掉了 Electron / 游戏启动器"报成功但起不来"
- 启动后尝试把目标窗口拉到前台（支持 `.lnk` 解析）
- 标签栏悬停面板每次弹出重申置顶，避免沉到别的窗口下面
- 修复「添加标签」会连弹两次输入框导致加不上的问题
- 移除壁纸模式下多余的提示文字

### 运行环境

- Windows 11（任务栏透明依赖 Win11 的 XAML 任务栏；岛台 / 标签栏 / 音频条在 Win10 上同样可用）
- 不需要管理员权限，不需要安装任何运行库

# English

## hotrainy v1.4

A small desktop enhancement toolkit for Windows 11: **real taskbar transparency, an island
launcher panel, a top edge tag bar, and an audio spectrum bar.**
Written from scratch in C++ / Win32 + GDI+, statically linked — **no admin rights, no runtime
redistributables, no registry footprint.**

### Download & install

1. Download **`hotrainy_setup.zip`** (0.63 MB)
2. Unzip to get `hotrainy_installer.exe` (1.33 MB, single file)
3. Double-click it → pick an install folder → confirm. Desktop and Start Menu shortcuts are created
4. After it starts, right-click the tray icon → **Settings**, and turn on "Transparency", "Island", "Audio bar"

To uninstall, run `uninstall.cmd` inside the install folder (it briefly restarts Explorer to release
the injected DLLs, then removes everything).

### New in this release

**Audio spectrum bar**
- Reacts to system loudness, with peak-hold and a silent state
- Adjustable horizontal / vertical length (+/− in Settings, 50 px per click)
- Four growth directions: up / down / left / right (switching direction swaps width and height)
- Drag the bar itself to move it; size and position are persisted
- Sits in the normal window band (not topmost), so it never covers other apps

**Single-file installer**
- Pick your install path, desktop / Start Menu shortcuts created automatically
- Does not write to system folders and does not touch autostart (enable it in Settings if you want)

**One-click uninstaller `uninstall.cmd`**
- Stops the app → removes startup entry and shortcuts → restarts Explorer to release the injected DLLs
  → deletes program files, config, logs and wallpapers → verifies leftovers → deletes itself

**Top edge tag bar**
- No longer pops up while a fullscreen game or video is running (`SHQueryUserNotificationState`)
- New "Wallpaper for tab" picker in Settings: give each tab's panel its own wallpaper
  (remembered by tab id, so adding/removing tabs never mismatches)

### Fixes

- Shortcut launching: the working directory is now the **target's own folder**, and forward slashes
  are normalised — this fixes Electron apps and game launchers that "succeeded" but never started
- After launching, the app tries to bring the target window to the foreground (handles `.lnk` targets)
- The tag bar's hover panel re-asserts topmost every time it appears
- Fixed "Add tab" opening the name prompt twice, which made adding a tab silently fail
- Removed a leftover hint text in wallpaper mode

### Requirements

- Windows 11 (taskbar transparency relies on the Win11 XAML taskbar; the island, tag bar and audio
  bar also work on Windows 10)
- No administrator rights, no runtime installation required
