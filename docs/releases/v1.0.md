# 中文

## hotrainy

Windows 11 桌面增强小工具：**任务栏真透明 + 岛台面板 + 顶部标签栏 + 音频波动条**。
纯 C++ / Win32 + GDI+ 手写，静态链接 CRT —— **免管理员、免运行库、免注册**。

> **这是第一版**，难免有 bug。遇到问题欢迎到 [Issues](../../issues) 提，或者直接**私信我**：GitHub [@HotRain927](https://github.com/HotRain927)。

### 功能

| 模块 | 说明 |
|---|---|
| **任务栏透明** | 注入 explorer，把 Win11 XAML 任务栏里的 `BackgroundFill` 隐藏掉，做到真透明（背景真的透出壁纸，而不是加一层半透明色块）。 |
| **岛台面板** | 任务栏上的 **H** 按钮，点开是仿手机桌面面板：内嵌搜索框、分类栏、大图标、长按拖拽排序、拖四角缩放，位置与尺寸自动记忆。 |
| **顶部标签栏** | 鼠标移到屏幕上边缘唤出，按标签分组显示桌面快捷方式；悬停/点击两种展开模式、右键增删改标签与排序、**每个标签独立壁纸**、滚轮翻页、面板内搜索。**全屏游戏/全屏视频时不弹出。** |
| **音频波动条** | 随系统响度起伏的频谱条（峰值保持、静音态）。横向/纵向长度可调，四种波动方向，按住本体拖动移动，位置与尺寸持久化；层级为普通窗口，不挡其他软件。 |

配套：托盘常驻无主窗口、单实例、explorer 重启后自动重新注入、崩溃守护；配置为单个 JSON（`%APPDATA%\hotrainy\config.json`）。

### 下载安装

1. 下载 **`hotrainy_setup.zip`**，解压得到 `hotrainy_installer.exe`（单文件）
2. 双击 → **选择安装位置** → 确认（会自动创建桌面快捷方式和开始菜单项）
3. 启动后右键托盘图标 → **设置**，打开「透明」「岛台」「音频条」

卸载：运行安装目录里的 `uninstall.cmd`，输入 `Y` 回车。它会结束程序、删掉自启项与快捷方式、
**重启一次资源管理器**（释放注入的 DLL）、删除程序文件/配置/日志/壁纸，最后自删。

### 运行环境

- Windows 11（任务栏透明依赖 Win11 的 XAML 任务栏；岛台 / 标签栏 / 音频条在 Win10 上同样可用）
- 不需要管理员权限，不需要安装任何运行库

### 使用速查

| 操作 | 说明 |
|---|---|
| 岛台面板 | 点任务栏上的 **H** 按钮；顶部窄边拖动移动，四角拖动缩放 |
| 标签栏 | 鼠标移到屏幕上边缘；标签上右键管理标签、设置该标签壁纸 |
| 壁纸 | 设置 → 外观 → **壁纸适用标签**，可为每个标签面板单独设壁纸 |
| 音频条 | 设置 → 系统 → 音频条：尺寸用 +/− 调（每下 50 像素），方向四选一，拖本体移动 |
| 搜索 | 默认热键 `Ctrl+Alt+Space`（可改） |
| 开机自启 | 设置里自行开关（安装程序不会替你打开） |

# English

## hotrainy

A small desktop enhancement toolkit for Windows 11: **real taskbar transparency, an island launcher
panel, a top edge tag bar, and an audio spectrum bar.**
Written from scratch in C++ / Win32 + GDI+, statically linked — **no admin rights, no runtime
redistributables, no registry footprint.**

### Features

| Module | Description |
|---|---|
| **Taskbar transparency** | Injects into `explorer.exe` and hides the XAML `BackgroundFill` of the Win11 taskbar, so the wallpaper really shows through instead of a translucent colour block. |
| **Island panel** | An **H** button on the taskbar opens a phone-style panel: embedded search box, categories, large icons, long-press drag sorting, corner resizing; size and position are remembered. |
| **Top edge tag bar** | Move the mouse to the top edge to reveal tabs of desktop shortcuts: hover/click expansion modes, right-click tab management and ordering, **a wallpaper per tab**, wheel paging and in-panel search. **Does not pop up while a fullscreen game or video is running.** |
| **Audio spectrum bar** | Reacts to system loudness with peak-hold and a silent state. Adjustable horizontal/vertical length, four growth directions, drag the bar itself to move it; size and position are persisted. Sits in the normal window band, so it never covers other apps. |

Also: tray-resident with no main window, single instance, automatic re-injection after an Explorer
restart, crash guard, and a single JSON config at `%APPDATA%\hotrainy\config.json`.

### Download & install

1. Download **`hotrainy_setup.zip`** and unzip it to get `hotrainy_installer.exe` (single file)
2. Double-click it → **pick an install folder** → confirm (desktop and Start Menu shortcuts are created)
3. After it starts, right-click the tray icon → **Settings** and enable "Transparency", "Island", "Audio bar"

To uninstall, run `uninstall.cmd` in the install folder and answer `Y`. It stops the app, removes the
startup entry and shortcuts, **restarts Explorer** (to release the injected DLLs), deletes program
files, config, logs and wallpapers, and finally deletes itself.

### Requirements

- Windows 11 (transparency needs the Win11 XAML taskbar; the island, tag bar and audio bar also work
  on Windows 10)
- No administrator rights, no runtime installation required

### Quick reference

| Action | How |
|---|---|
| Island panel | Click the **H** button; drag the top strip to move, drag corners to resize |
| Tag bar | Move the mouse to the top edge; right-click a tab to manage it or set its wallpaper |
| Wallpapers | Settings → Appearance → "Wallpaper for tab" — one wallpaper per tab panel |
| Audio bar | Settings → System → Audio bar: size with +/− (50 px per click), four directions, drag to move |
| Search | Default hotkey `Ctrl+Alt+Space` (configurable) |
| Start with Windows | Toggle it in Settings (the installer never enables it for you) |
