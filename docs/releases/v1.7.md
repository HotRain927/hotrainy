# hotrainy v1.7 —— 音频波动条重做 / 标签底色收敛 / 若干交互修复

> 版本号说明：发行序列 **v1.x**（承接 v1.6），程序内部版本号 `11.2`（设置窗口标题栏显示的就是它）。

## 音频波动条：全新横向声波丝带

原来的音频条是**一列竖条**，本版整体重做为**横向声波丝带**：

- 以中线为轴、沿横向起伏的丝带，**内亮外淡**、由内到外一层层均匀退色
- **上下不对称**：上半个起伏明显大于下半个（更接近真实声波观感）
- **音量为零时**不再整条消失，改为显示**三条细线**，安静但看得见
- **五档色调**（设置 → 系统 → 「音频条色调」）：
  **黑 / 白 / 蓝 / 红 / 黄**，每档都由**两种十分相近的色相**掺杂而成，不再是单一死色
- **默认尺寸/位置更合理**：宽约屏幕 1/3、位于屏幕下方；仍可在设置里用
  「音频条横向长度 / 纵向长度」自由调整，**拖动后的位置会被记住**
- **音频条的开关状态现在跨启动保持**（以前每次启动都会自动关闭）
- ⚠ **移除**了旧的「音频条波动方向」设置项（新丝带是固定横向，不再需要）

## 标签栏：底色只在自己的边框内

以前整条栏铺一层底色，会溢到每个标签的边框外面（标签之间的缝里也有底色）。
现在底色**逐标签、逐图标格**填充，**只落在各自的圆角边框内**，标签之间的缝透出后面的壁纸/任务栏。

## 其他变更

- **壁纸模式修复**：上传的壁纸现在会真正显示在标签面板上（此前该绘制调用一直缺失，
  导致"选了壁纸却看不到"）
- **搜索框跟随模式**：跟随资源管理器 / 文件对话框时，**手动调整过的大小会被保留**
  （此前高度每次打开都会被目标窗口重算）
- **面板雾化浓度提高**，四种面板（标签面板 / 岛台 / 设置窗 / 搜索框）观感统一
- **标签面板悬停响应更快**（判定间隔 35ms → 12ms）
- **岛台 / 设置窗拖动更顺滑**：拖动中只重新提交画面、不再整帧重画；同时修掉了拖动时的频闪
- **代码清理**：删除了若干确认无人调用的死代码（旧抓屏管线残留、峰值保持残留、实底分支残留）

## 安装

下载 `hotrainy_v1.7_win64.zip`，解压后运行 `install.cmd`（或直接跑 `hotrainy.exe`）；
卸载运行 `uninstall.cmd`。

- 运行环境：**Windows 11**（任务栏透明与岛台按钮依赖 Win11 的 XAML 任务栏，不支持 Windows 10）
