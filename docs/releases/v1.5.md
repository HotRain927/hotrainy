# hotrainy v1.5 —— 面板视觉 / 交互 / 拼音搜索 / 结构重构

> 版本号说明：发行序列是 **v1.x**（承接 v1.4），程序内部版本号为 `11.2`
> （设置窗口标题栏显示的就是它）。

> 特点：Windows 11 任务栏真透明 + 岛台面板 + 顶部标签栏 + 音频波动条。
> C++ / Win32 原生，**免管理员、免运行库**（静态 CRT，拷走即用）。

## 面板视觉
- **外阴影**：悬停面板 / 岛台 / 设置窗三处统一（窗口向外扩留白，内容坐标一像素不动）
- **真圆角描边**：改用标准 SDF，修掉"边框四角是断口"的老问题
- **雾化背景**：「面板透明度」滑块改成给**背景**加雾（0 = 纯透明），不再把文字/图标一起变透明；四个窗口（面板/标签栏/岛台/设置）浓度一致
- 全界面文字统一**白字黑边**（深色底、浅色底都读得清）
- 标签栏：每个标签 / 每个右侧图标各一圈类矩形圆角框；去掉那条横贯全屏的黑线

## 交互
- **拖动排序**：残影做成"面板同款"（柔和阴影 + 细玻璃边）；其它格子**每格独立缓动**顺滑让位（不再先弹回再推）
- **岛台从任务栏图标位置"长出来"**（190ms easeOutCubic + 淡入）
- 修掉"点开面板时会自动抓起一个快捷方式"
- 悬停面板**不用再抖鼠标**：鼠标停在标签上也会弹（原来只靠 WM_MOUSEMOVE 驱动）
- 面板展开去掉两处白干抓屏：实测合计 31ms → **16ms**（抓屏 0ms）

## 搜索
- **拼音搜索**：中文文件名可以用全拼（gongzuobaobiao）或首字母（gzb）搜，多音字（银行 → yinhang/yinxing）也覆盖
- 索引范围固定**全盘**，删掉「索引范围」「搜索目录」两个控件
- 修掉"改搜索快捷键总是提示已被占用"（`formatHotkey` 少写了一个 `+`）
- 搜索框那条刺眼的白底去掉

## 修复
- 快捷方式图标只剩白色剪影（单位混用）
- 面板 / 岛台 / 设置窗能点到背后的窗口（分层窗口命中只看 alpha）
- 拖动放下的瞬间窗口"被关掉又打开一下"
- 任务栏右侧文字颜色有时跟设置不一致（注入侧不记策略 + 状态机不收口）
- 「文字颜色」设置的作用范围收敛到任务栏右侧系统文字

## 工程
- **结构重构**：`src/app/main.cpp` 1730 行 → **924 行**；28 处模块接线 + 16 个设置键按归属拆到各模块 `xxx_wire.cpp`
  → 以后加/改某个模块只动对应目录
- 新增两个**回归单测**（`tests/`，挂进 CMake）：快捷键文本往返（1..0xFF 全覆盖）、拼音形式
  —— 这轮两个真 bug 就是它们抓出来的
- 单测在重构后仍然全过（`good=255 bad=0` / `fails=0`）

## 安装
下载 `hotrainy_v11.2_win64.zip`，解压后运行 `install.cmd`（或直接跑 `hotrainy.exe`）。
卸载运行 `uninstall.cmd`。
