# hotrainy v1.8 —— 录屏冲突修复 / 设置窗口修复 / 内存占用大幅下降

> 版本号说明：发行序列 **v1.x**（承接 v1.7），程序内部版本号 `11.2`（设置窗口标题栏显示的就是它）。

## ⚠ 本版最重要的是这一条：修复与 NVIDIA 录屏的冲突

**v1.7 及更早版本在运行时会让你无法录屏** —— 表现为 NVIDIA 的即时回放 / 录制
提示"**有受保护的程序正在运行**"，完全无法开始录制。

原因：任务栏上那个小按钮（岛台按钮）窗口被设置了
`SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` —— 它的系统语义是
"本窗口对任何屏幕捕获不可见"。但 Windows 会因此把**整个程序**登记为
"受保护内容"报告给捕获接口，而 NVIDIA 的做法是**检测到受保护内容就整段拒绝录制**
（不是只把那一个窗口画黑）。

这一句原本只是为了"让鼠标悬停任务栏时，那个 2×2 小按钮的预览框显示空白"（纯外观），
代价却是整个系统的录屏能力。**v1.8 已移除它**，录屏恢复正常。

> 唯一的副作用：悬停任务栏时，那个小按钮的预览框里会显示它本身（一小块方块）。
> 我们评估后认为"用一小块方块换回整个录屏功能"是完全划算的。

## 本版其他内容

### 修复：设置窗口打不开（v1.7 引入的回归）
v1.7 的内存优化里有一处误改，会让设置窗**打开后整窗空白**（看起来就像打不开）。
v1.8 已修复，并顺手在提交画布前加了兜底：**绝不提交 0 尺寸画面**。

### 内存占用大幅下降
- **WorkingSet：约 198 MB → 约 97 MB**（-51%）
- **句柄数：732 → 330** 左右
- 做法：隐藏/关闭的窗口**真正归还画布内存**（原来只是清零、内存仍占着），
  并收紧拼音缓存上限

### v1.7 已有的音频波动条等改动照常保留
横向声波丝带、五档色调（黑 / 白 / 蓝 / 红 / 黄）、由内到外均匀变淡、
上下不对称、零音量显示三条细线、音频条开关与尺寸位置跨启动保持，等等。

## 安装

下载 `hotrainy_v1.8_win64.zip`，解压后运行 `install.cmd`（或直接跑 `hotrainy.exe`）；
卸载运行 `uninstall.cmd`。

- 运行环境：**Windows 11**（任务栏透明与岛台按钮依赖 Win11 的 XAML 任务栏，不支持 Windows 10）
